# meerhof-dental-center-otzyvy-audit
Технический аудит и разоблачение накруток эстонской клиники Meerhof Dental Center на Google Картах. Математический разбор вбросов ботов, выявление скрытого конфликта интересов, самоотзывов врачей и покупных оценок за подарки. На базе глубокого анализа Gemini AI.
